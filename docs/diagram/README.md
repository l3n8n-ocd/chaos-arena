# Architecture diagram

`docs/architecture.svg` (and the `architecture.png` export) is generated by `make_diagram.py`.
Every icon is embedded in the SVG, so it renders anywhere with no external files.

Regenerate it:
```bash
cd docs/diagram
npm install
npm run build
```
